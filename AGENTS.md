# Site existente: preservar a implementação
Este projeto é um site completo em HTML, CSS e JavaScript com Vite. Não é um briefing para gerar outro site.
- Preserve o design e o conteúdo existentes, salvo mudanças pedidas pelo usuário.
- Não substitua por um template, não remova imagens e não converta para React sem pedido explícito.
- index.html: marcação e textos editáveis. src/styles.css: estilo atual.
- src/interactions.js: menu, galeria e formulário. src/motion.js: animações.
- src/config.js: número do WhatsApp. public/assets: imagens WebP locais.
- Instalar: npm ci. Executar: npm run dev. Validar: npm run build.
- dist é gerado e não deve ser editado manualmente. Não use Express.
- Preserve Vite, package-lock.json e vercel.json. Não são necessárias chaves de API.
- Após mudanças de markup, mantenha os seletores usados pelos scripts.
